### Difference between Syntax and sematics?
- Syntax - it means code should be correct according to programming language rules.
(eg. int a=45; not int 1a=45;)
Errors which occur due to wrong syntax are called Syntax Errors.
- Semantics - it means your code should be logically correct.
(eg int a=45 not eg int a=45.4)
Errors which occur due to wrong logic are called RUNTIME ERROR.

### Rules for naming Variables or Identifiers.
* name only containers alphabets, digits, underscore(_) and $
* name cannot be starts with a digit
* name cannot be a keyword.
* name can't have any space (whitespace is not allowed)
* case- sensitive

### What does the assignment operator (=) do?
* it assign the value from right hand side value to the left hand side value 
Eg. int a = 45;
So here, value 45 is assigned to variable "a".

### Why do we declare the type of a variable bbefore using it?
* because Java is a Statically Typed Language in which we have to tell the compiler the type of data we are working on.

### Why is = is called assignment operator not equality?
* because it assigns the RHS value to the LHS whereas equality operator(==) checks either RHS and LHS is equal or not.
